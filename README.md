# 进程流量监控助手 🖥️

基于 C/S 架构的 Windows 进程级网络流量监控系统：实时统计每个应用程序的上行/下行流量与端口占用关系，支持历史数据可视化查询、流量配额告警与断网控制。

## ✨ 功能特性

- **进程级流量统计**：scapy 抓包 + 端口→PID 映射，将网络流量精确归属到具体进程
- **实时监控面板**：TOP10 进程流量柱状图，3 秒自动刷新
- **历史数据可视化**：按日查询进程流量占比饼图 + 24 小时趋势折线图 + 明细表
- **数据持久化**：60 秒聚合窗口写入本地 SQLite，支持任意历史日期回溯
- **流量配额规则引擎**：针对单个进程自定义配额，超配额告警或即时断网
- **数据导出**：一键导出当日流量明细 CSV，可用 Excel 进一步分析

## 🏗️ 系统架构

```
┌─────────────────────────┐     本地Socket      ┌──────────────────────────┐
│  后台数据采集服务（无界面）  │ ◄─── JSON协议 ────► │  前台展示界面              │
│  collector/              │                    │  ui/ (Flask + ECharts)   │
│                          │                    │                          │
│  ├─ pid_mapper 端口映射   │                    │  ├─ 实时监控面板           │
│  ├─ sniffer 抓包引擎      │                    │  ├─ 历史查询 + 24h趋势     │
│  ├─ aggregator 流量聚合   │                    │  ├─ 规则管理界面           │
│  ├─ storage SQLite持久化 │                    │  └─ 告警记录 + CSV导出     │
│  ├─ rules 配额规则引擎    │                    │                          │
│  └─ ipc_server Socket服务 │                    │                          │
└─────────────────────────┘                    └──────────────────────────┘
```

**核心技术点**：Windows 下 psutil 不提供每进程网络 I/O，采用"抓包→按本地端口反查 PID→按进程聚合"的间接方案；断网控制采用"防火墙出站规则 + 强制关闭存量 TCP 连接"组合策略实现即时生效。

## 🛠️ 技术栈

- **语言**：Python 3.13
- **抓包**：scapy（需 Npcap 驱动 + 管理员权限）
- **进程信息**：psutil
- **数据库**：SQLite（60s 聚合窗口，时间/进程双索引）
- **IPC**：本地 Socket + JSON 文本协议（8 个命令）
- **前端**：Flask + ECharts

## 🚀 快速开始

```bash
pip install psutil scapy flask

# 终端1（管理员）：后台采集服务
python collector/main.py

# 终端2：前端界面
python ui/app.py

# 浏览器访问 http://127.0.0.1:5000
```

## 📂 目录结构

```
collector/
  main.py        # 一键启动入口
  pid_mapper.py  # 端口→PID 映射表（5s 刷新，线程安全）
  sniffer.py     # 抓包引擎（方向判断 + 进程归属）
  aggregator.py  # 60s 窗口聚合 + 内存环形缓冲
  storage.py     # SQLite 持久化与查询
  rules.py       # 配额规则 + 告警 + 防火墙断网控制
  ipc_server.py  # 本地 Socket 服务端（JSON 协议）
ui/
  app.py         # Flask 入口 + 8 个 API 路由
  ipc_client.py  # Socket 客户端封装
  templates/     # 四 Tab 单页界面
  static/        # ECharts
```
